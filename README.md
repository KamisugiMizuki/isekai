# isekai

Veranima World（暂名）——一个持续运行的异世界。用户通过与世界内角色的对话（经由角色专属的双向联络方式），碎片化地发现这个世界的历史、人文与重要事件；世界不依赖用户在线而存在。

> 状态：总设计已收敛（2026-09-19，V1.9）。本项目独立于 veranima-companion；后者作为设计参考与资产来源。
