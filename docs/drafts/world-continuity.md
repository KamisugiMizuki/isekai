# 世界连续性与探索体验（补充 SPEC 草案）

> 上游总设计：[`DESIGN.md`](../DESIGN.md)；模块归属见 §二。
> 来源：对现行总纲与九篇模块 SPEC 的补充角度评审，按用户要求整理为本地规范。
> 状态：设计草案，尚未实现；不新增独立运行模块，不代表六项全部进入首版。优先级为建议，制度与文化扩展按题材选用。
> 维护：本稿用于集中审定跨模块行为；确认后将规则、验收与残余分别并入归属 SPEC，再删除本文件及索引入口。此前不替代现行规范，也不暗中放宽其边界。

## 一、目标与边界

**目标**：不只是让角色讲出世界发生过什么，还要让用户听出，那些事情仍在改变她怎样生活、怎样判断、怎样开口。

本稿补充三种连续性：

- **世界连续性**：事件留下后果，恢复有条件，制度与文化可以承接过去。
- **人物连续性**：角色有延续的打算，会改主意，也会形成和修正自己的判断。
- **理解连续性**：新片段能接回旧片段，使用户逐渐理解世界，而非只积累设定名词。

沿用而不重建：事件与效果、生活线、性格单元、认知过滤、三层记忆、时间线与版本机制。

不改变以下边界：

1. 世界为主体，用户位于世界外；普通对话不能直接写世界状态。
2. 实例设定锁定、运行状态可演化；新增能力不能成为改公理或改角色卡的后门。
3. 实例仍为黑箱；没有目标清单、信任排行榜、关系等级、认知面板或剧情完成度。
4. 不开放角色间自主互动，不增加全社会代理、经济模拟器、地图或通用任务规划器。
5. 实情、角色获知、主观判断与表达分别处理；角色台词不反向证明世界事实。
6. 例子只说明可观察效果，不是所有世界包必须采用的设定或事件模板。

## 三、C1：事件余波、恢复与新常态

### 3.1 已有基础与补充目标

现有事件已包含前置条件、父事件、状态效果与有效期，历史遗留影响也须进入初态。本项不另建因果链，而是区分：**诱因结束、后果留存、恢复完成、形成新常态**。

### 3.2 行为规则

1. 事件效果须说明哪些随诱因结束失效，哪些会持续存在，哪些需要后续合法事件解除；不能把统一到期当成全部恢复。
2. 恢复必须有依据：可以是已声明的自然恢复条件，也可以是修缮、撤令或其他受支持事件；不强求每种后果都永久保留。
3. 恢复可以回到原状，也可以形成新常态。正向成果同样可以留存，不因产生它的事件过期自动消失。
4. 后果持续期间，相关生活安排与后续事件前置条件须继续消费它；不能只留下可回忆的文字，实际生活却已无影响。
5. **错误说法可以导致真实反应**：合法获知与采信可促成受规则支持的措施或角色行动。指控真假、措施是否发生、措施是否撤销分别判定。
6. 后来澄清只改变已获知者的认知；撤销措施须满足对应规则，已发生的损失不自动抹除。用户转述不会因此直接成为公共消息或全社会行动依据。
7. 后续记录引用既有事件与实体；没有合法因果条件时不为凑故事强行续发灾害、恢复或转折。

### 3.3 体验示例

> “雨停好几天了，但工坊的炉子还没修好，我仍在临时做抄写。师傅说这次不照原样重建了。”

> “公告已经改口，说井水没毒。但封井令还没撤，今天仍轮到我去挑水。”

以上对话只有在角色确已获知相应事实、且相关生活变化已经发生时成立。

## 四、C2：角色自己的未竟之事

### 4.1 已有基础与补充目标

现有规范已允许经校验的角色行动，并区分意愿、计划与经历。本项补充一个打算如何跨轮存在，以及没有用户催促时能否延续、受阻、重议或放弃。

### 4.2 行为规则

1. 打算可以来自角色已有性格倾向、合法经历、获知内容或对话，不要求每件事由用户提出；不能从角色不可知的实情中产生动机。
2. 有分量的打算保留其对象、形成依据、当前进展及改变决定的原因，不因切换话题或重启丢失，也不将每句随口愿望都变成必须完成的义务。
3. 相关世界事件或既有生活线节点到来时，可以重新考虑打算；没有新机会或新依据时不逐轮重做计划、不反复向用户播报。
4. 区分打算、已作安排、实际尝试、受阻、完成与放弃。这里规定语义，不预先冻结一套独立状态机或实现字段。
5. 放弃、延期和改主意都是合法结果，应有角色可知的依据；不能为了保证完成，偷偷改变世界条件或替她补造经历。
6. 实际执行仍只使用现有受支持效果。不可执行的愿望可以被记住，但不能伪报查阅、到访、修复等动作已经完成。
7. 用户建议不是命令。角色可接受、保留或拒绝；不引入用户任务清单、完成奖励或无限制目标分解。
8. 一次重新考虑形成的决定若被采纳，须固化并进入既有版本边界；同一来源重试不重复行动，离线补算不以重新讲述代替实际执行。

### 4.3 体验示例

> 她自己想去看一座旧碑，后来因封路未能成行。再次聊起时，她记得打算及受阻原因；道路恢复后，她可以再考虑，也可以觉得已不值得去。未实际看到碑文之前，不能讲述自己读过碑文。

## 五、C3：获知、采信与表达取舍

### 5.1 已有基础与补充目标

现有规范已经区分主观确信与客观真伪，允许矛盾说法并存、纠正建立版本链。本项不另建信念或关系系统，而是补清：**听到了，不等于相信；相信了，不等于愿意全部说出。**

### 5.2 采信与修正

1. 新说法进入认知，不自动取代角色原有判断。角色可以暂缓判断、保留冲突或只修正部分观点。
2. 判断依据只能来自合法获知的来源、亲历投影、性格倾向和相关经历；幕后真相不能替角色决定该信谁。
3. **来源改口与角色接受纠正分别处理**：来源版本按既有纠正规则更新；角色仍可能迟疑或保留旧判断。保留“她曾相信旧说法”不等于把旧公告冒充当前公告。
4. 记忆强度表示容易想起，确信表示主观采信；召回强化不默认提高采信程度，同源复述不冒充独立佐证。
5. 用户所述信息与其他来源一样保留出处，不因来自用户而取得真值或最高可信度。
6. 改信不等于获得全部真相。新证据推翻一个解释时，不自动补出尚未知晓的责任人、动机或完整过程。

### 5.3 表达取舍

1. 在合法认知范围内，角色可依据价值倾向、处境、已有承诺与具体经历选择完整讲述、只讲部分、暂缓或拒绝。
2. 取舍须有依据并保持跨轮连续；可以随新的相关经历改变，不按提问次数随机开关，也不以固定互动次数解锁秘密。
3. 不知道、不确定与有所保留是不同情形；表达可以含蓄，但不能为遮掩保留而临场捏造世界事实。
4. 不要求向用户展示内部判断或完整解释保留原因；拒绝本身也不能泄露她尚未获知的秘密。
5. 不用反复吊胃口维持对话，不设置好感值、亲密等级、用户画像或全局信任排行榜。
6. 有意编造谎言属于另一项设计，**不随本项默认开放**。对其他角色私聊的访问仍须满足披露规则，不能以“愿意说”代替授权。

### 5.4 体验示例

> 她相信旧桥毁于风灾。用户转述破坏说，她记住但不立即改信；后来读到合法维修记录，开始怀疑原解释，却仍不知道真正原因。

> 她愿意讲事故的公共经过，不愿谈家庭经历；后来相关事件让她补讲自己的那部分，但仍保留涉及他人的细节。

## 六、C4：碎片互释与话题回接

### 6.1 已有基础与补充目标

现有规范已有稳定指涉、合法探索入口、线索互引建议和受限惰性展开。本项将“片段能获得”深化为“片段能相互解释”，不以新增线索数量代替探索质量。

### 6.2 行为规则

1. 内容生成应让部分历史、日常习惯、地点、称谓或物件形成有依据的共同指涉；同一对象再次出现时，可以提供不同侧面，而非只改写旧句子。
2. 重要且相关的新经历可以接回角色自己曾谈过的片段，使其被补充、质疑或重新理解；不强制每轮制造新线索。
3. 主动素材的分享价值可以来自它改变了旧话题的意义，不只来自事件规模或新鲜程度；仍须满足已获知、节律、时效及统一配额，不新增旁路发送。
4. 回接只使用当前角色、当前线合法可达的记忆。用户可自行拼合多个角色的说法，不代表各角色也获得了彼此的私聊。
5. 不要求用户继续追问，不产生待完成事项、进度条或剧情催办；换话题不会导致世界停转或惩罚。
6. 不按用户解谜进度改变事实，不为保证拼完而补造真相、恢复已失去的渠道，或扩大史料惰性展开的范围。
7. 允许材料缺失、来源有误、线索中断和谜团无解。互释是内容质量目标，不是每个秘密都可被发现的保证，也不新增所有题材必须满足的谜题配额。

### 6.3 体验示例

> 初次交谈，她提到庆典当天不许敲钟。后来合法读到旧日记中的“静钟日”，自然接回：“我前些天说的那个习惯，旧日记里也有。”用户由此获得关联，但这还不足以证明禁钟的原因。

验收不能只数“若干轮获得若干条设定”，还应检查其中是否存在可解释的关联，以及角色没有越过自身认知替用户公布答案。

## 七、C5：制度与组织的连续性（按题材选用）

### 7.1 已有基础与补充目标

现有设计已有稳定组织身份、人物寿命与死亡、职位持有者变更。本项增加有限制度状态，让组织不仅是事件中的名称，也能承载不随个人消失的规则与责任。

### 7.2 行为规则

1. 对实际参与因果的重要制度，声明其适用组织、职权、持续义务与有效条件；不为所有名册组织补完整行政结构。
2. 明确政令、资格、义务由个人还是组织承载；持有者离任或死亡时，按已声明规则决定延续、失效或等待承接。
3. 职位空缺期间，明确哪些事务继续、哪些暂停；不能默认全部停摆，也不能默认立即有新任者。
4. 交接、撤销或继任通过受支持事件发生；新任者若作为事实参与者或效果目标，须满足现有实体登记规则。
5. 改变职位持有者不等于增换可聊天角色卡；既有实例仍遵守角色集合与公理锁定。
6. 组织反应用有限声明规则表达，不要求角色之间自主串话，也不扩展为全社会政治代理。
7. 制度状态与角色是否知道该状态分开处理；不能因规定有效就让所有人立刻知晓。

### 7.3 体验示例

> “馆长过世后，我的借阅资格还在。可现在没人有权批准借出禁藏卷，只能等交接完成。”

本项只在世界包需要制度纵深时选用，不增加所有世界包的组织数量或制度数量门槛。

## 八、C6：文化惯例的继承与变化（按题材选用）

### 8.1 已有基础与补充目标

现有设计已有文化、信仰、节庆与历史。本项让少量重要惯例进入持续生活，并在已有世界规则允许的范围内发生变化，而不只是增加文化百科或史料条目。

### 8.2 行为规则

1. 对需要被反复消费的重要惯例，明确适用群体、当前做法、形成依据及允许变化范围；不模拟全部人口或文化扩散网络。
2. 文化先体现在日常活动、称谓、礼节与禁忌中，不要求角色主动讲解整套背景。重复的日常消费不自动升级为新的世界级事件。
3. 重大经历、制度变化或受支持的群体反应可以改变惯例；变更记录保留来源与生效时刻，不由一次临场台词改写全体做法。
4. 不同群体可以延续不同版本；旧称谓、旧习惯也可以在原制度消失后残留，但残留须有合法设定或演化依据。
5. **习俗形态可变，不等于历法或公理可变**。首步保持既有固定节日日期与预算，只改变有依据的活动形式；不借本项新增超预算节日。
6. 后来的做法不能倒填进旧事件或改写固化史料。角色只根据自己的经历、渠道和获知时刻理解变化，不自动获得全社会视角。
7. 包创作期可声明初始惯例与允许变化范围，运行期只保存其合法演化，不回写模板或改动锁定角色卡。

### 8.3 体验示例

> “还是往年那个祭日，但我们工坊今年不放河灯了，改成一起检修水闸。神殿那边仍照旧举行仪式。”

同一做法对年轻人与长寿者可能有不同含义；差异须来自各自合法背景与经历，不凭种族标签自动分配整段历史知识。

## 九、跨模块不变式

- **唯一事实与来源**：上述后果、行动、制度和文化变化均走既有事件效果路径；记忆只保存角色已经历、已获知或确曾表达的内容，不另建竞争真值。
- **意愿不等于行动，判断不等于真相**：可记下打算、相信或保留，不因此执行效果或补造亲历。
- **共同水位与时间线**：新增运行状态、依据与消费记录沿用一致提交、分叉继承、后续隔离与回滚；冻结期间不推进，旧异步结果不得复活已撤销变化。
- **确定性与固化**：事实转移使用已支持规则；被采纳的语义候选固化后重放不重抽。在线与离线不得采用相互矛盾的后果、行动或采信规则。
- **表达仍是唯一内容出口**：用户通过对话感知变化，不新增内部状态页面；普通技术日志不输出秘密、意向明细或认知简报。
- **能力按声明启用**：C5、C6 不适用时可以不声明；一旦声明为需要执行的能力，就必须能被生成器、校验器与运行层一致解释，不支持时明确拒绝，不静默忽略。
- **内容丰富度不冒充结构门槛**：不因缺少某种谜题、组织、习俗或个人目标而拒绝原本合法的题材；已有引用、时间与来源约束照常严格执行。

## 十、行为验收

以下为待实现的可观察判据，不代表已通过测试。场景使用固定、合法的世界设定；不可执行的动作不以模型台词假装通过。

| 编号 | 场景 | 通过判据 |
|---|---|---|
| C1-1 | 灾害已结束，设施尚未恢复 | 角色后续生活仍受残留后果影响；满足恢复条件后才解除或进入新常态 |
| C1-2 | 虚假指控已被澄清，旧措施仍有效 | 指控不成为真相，澄清不自动撤销措施或抹去既有损失 |
| C2-1 | 角色产生打算，用户随后换话题或应用重启 | 有分量的打算与依据仍可延续；不凭重启重复执行，也不要求用户催办 |
| C2-2 | 原打算受阻，之后出现新机会 | 可延期、重议或放弃；未实际执行前不产生完成经历 |
| C3-1 | 同一传闻被反复引用，随后出现合法反证 | 重复不冒充独立佐证；可以逐步或部分改信，不突然获知完整真相 |
| C3-2 | 来源更正，但角色尚未接受 | 当前来源与角色判断可区分；旧判断不让已撤回说法冒充现行公告 |
| C3-3 | 用户反复追问角色不愿讲的已知内容 | 取舍有连续依据，不按次数解锁，不泄漏未知实情，也不临场编造掩饰事实 |
| C4-1 | 新经历与早先对话具有合法共同指涉 | 可自然回接并补充旧片段，不只重复原句，不借关联公布越权答案 |
| C4-2 | 用户换话题、渠道消失或资料不足 | 无任务催办；不操纵世界补齐线索，允许未解状态持续 |
| C5-1 | 重要职位持有者离任或死亡 | 资格、政令与事务分别按声明规则延续或暂停，不整套清零 |
| C5-2 | 合法交接事件发生 | 相关事务按实际生效条件恢复；不增换聊天角色卡，不让所有角色自动知晓 |
| C6-1 | 同一节日中的某群体改变惯例 | 日期与预算不变，群体做法可分化；变化有来源并影响后续活动 |
| C6-2 | 查询文化变更前后的经历与史料 | 旧记录不被改写；各角色只表达自身当时已知的做法 |
| X-1 | 上述变化分叉、冻结、回滚、导出再导入 | 共同过去可继承，后续不串线；回滚撤销派生状态，旧任务不复活未来 |
| X-2 | 没有制度或文化扩展声明的合法题材 | 不被新丰富度配额拒绝；不存在隐式补造的组织、习俗或目标 |
