## 一、模型

**史书 = 公共叙事层的一种体裁 + 一个来源；历史数据是事件记录，史书是它的投影。**

不新建独立历史真值模型：实情在事件骨架，史书条目是说法，沿用 `EVENT_ENGINE_SPEC.md` §二的事件、说法与来源关系。**同表存储不等于重复执行历史效果；内容被生成也不等于角色已经获知。**

## 二、对象

| 对象 | 内容 | 归属 |
|---|---|---|
| 事件（回填） | 世界时刻、主体、事实骨架、影响；与运行期事件**同表** | 事件模型 |
| 条目 | 对事件或命题的表述：体裁、措辞、来源；不要求所述命题为真 | 说法（来源 = 载体） |
| 载体（传本） | 稳定标识、作品归属、名称、编者、止笔与成书时刻、覆盖区间、体裁与立场 | 实体（物件）+ 来源引用 |
| 体裁 | 官修编年 / 地方志 / 野史 / 碑刻 / 创世记述……（清单不冻结） | 生成侧文风 + 选择性规则 |

- 同一作品的不同传本保留**共同作品归属 + 各自标识**，不建传抄血缘树。「同一事件 + 不同来源」只证明材料谈及同一件事，不能单凭它认定同源或改写。
- 载体回答「哪份材料」，渠道回答「如何接触」；沿用既有渠道与认知条件，不因书已登记就让所有角色读到。
- **缺载是合法形态**：一档编纂时确定各传本的选载范围，不要求每个来源覆盖每个事件。已确认缺载与尚未生成 / 展开必须区分；惰性展开不能把缺载偷偷补成有载。
- 缺载本身不证明刻意删改。认定避讳、改写或残本保留旧文须有设定或来源依据；这些依据也须经认知过滤，不能因内部已知就直接告诉角色。

## 三、编者（两分）

- **古史书**：编者是可稳定指涉的历史人物资料（身份、名字、年代、立场），**不作为世界实体、不参与运行**。同一编者的署名跨书保持一致；角色可以依据已获知资料谈论他，不必为此建立日程或活跃角色。
- **近史书**：编者**作为实体**，可被引用、可被事件影响、可通过角色对话被问及。

两类均须检查编纂活动与编者在世区间相容；遗稿、后世整理须区分原编者与整理者，不把传本成书时刻一律当成原编者仍在世的时刻。

【缺口】古近分界按世界包声明的年代阈值划定；具体阈值及年龄 / 特殊寿命的校验表达方式留待实现。**校验义务不后置，年代分类也不代替在世校验。**

## 四、对抗性叙事（说法层的生成来源）

同一事件出现两种说法是**常态**，不是例外。三个基本型：

1. **同源异文**：抄写讹误、年代记混。
2. **立场改写**：上位不光彩 → 官方本改写；对敌人抹黑 → 敌我两说；为尊者讳 → 缺载。
3. **残本流失**：官方本改写后，只有民间残本保留旧记载。

- 神话 / 创世记述也是史料；**任何体裁的说法均可真实、片面或完全虚构**，不为神话单设真假权限。
- 区分「某项指控确实被编入史书或流传」与「被指控之事真实发生」：前者可作为事件，后者只是说法指称的命题。沿用既有风闻规则，假记载不能自动产生其所述事件的事实效果。
- 真相只在实情层；角色依据接触到的来源和自身判断形成信念，多种矛盾说法可并存。确信度不等于真伪，新近获得的说法也不自动成为客观真相。

## 五、生成次序与分档

### 5.1 创建期：先约束，后补史，再锁定

1. **约束输入**：已确认的历史、世界公理、当前局势与角色背景是硬约束；复用已有事件与说法引用，只在空白处补史，不随机覆盖已有锚点。
2. **骨架回填**：按本次创建固定的种子、生成规则版本与受支持的因果规则，分时代抽样生成合法骨架。独立预算，不占运行期每日密度；无合法候选则留白，不为凑量添加事实。确定性只保证复现，不能替代因果校验。
3. **一档文本**：按传本与卷批量编纂，暂按十年一卷、10–20 条一批，全量生成所选条目的「一句话」级文本并确定选载范围。LLM 按骨架与传本立场生成文本及说法；校验、重试与兜底沿用事件引擎，不由文本反向决定事实效果。
4. **联合校验与固化**：检查历史与当前局势相容、实体与因果引用有效、各传本来源合法，并在回填后最终校验角色初始知识引用及范围。沿用实例创建的原子边界，一起固化为初始快照；失败不留下可运行的半个实例。若必须改变已确认内容，返回创作阶段重新确认，不暗改世界包或角色卡。

历史后果及仍有效的影响须已纳入初始状态，运行从初始时刻继续。**回填记录不再次施加灾害、性格冲击或获知效果，也不因导入 / 启动批量成为新近主动素材。** 角色后来合法读到旧史料可以形成新的获知经历，但不是历史事件重新发生。

### 5.2 二三档：既定内容的惰性展开

被追问、被引用或成为剧情支点时，可将已有条目展开为段 / 本末；通过校验后以关联原条目的**新增派生记录**固化，不原地改写事件或最初文本。

- **只展开既定内容**：依据已确定的事实与该传本的说法，不新增尚未确定的参与者、生死、关键原因、结果或状态效果。「没有推翻旧句子」不足以证明合法；补出死因或幕后责任人同样可能是在创造新事实。
- **留白不临场填真相**：依据不足就保留不知道，不把未展开冒充该来源未记载。新增历史事实不属于本轮文本展开权限；不同来源之间既定的矛盾仍合法，不以实情强行改正错误史料。
- **物化不等于获知**：系统生成文本不虚构读书经历。只能返回角色原本掌握范围内的展开；新增范围须经合法接触与获知，不能因用户追问就自动解锁整部史书。
- **共同过去不随提问改变**：展开只使用该传本对应的固化输入，不使用后来局势、分叉后对话或角色私有知识。同一实例中，共同过去的同一传本 / 条目复用已采纳的展开结果，不按角色或时间线各写一份相冲突的史料。
- **派生表示不成为第二份真值**：展开不是新发生的历史事件，不产生事实效果。获知范围、引用经历及派生记忆仍随角色和时间线版本化；回滚撤销后来的获知，派生缓存即使保留也不得越权返回。

## 六、时间、校验与视图

- **时间基元与语义**：统一用世界秒，但区分事件实际发生、传本止笔 / 成书 / 可传播、角色获知及记录固化的时点。后台何时生成文本不能冒充事件发生或角色阅读的时刻。
- **史料自称年代**：纪年写法属于说法，可记错，但不能覆盖权威事件时间。「三百年前」绑定该句的叙述时点；角色转述时另按当前世界时刻换算，不随查询日期悄悄改写原文。
- **止笔与传播**：止笔界定该传本收录材料的截止点；之后形成的材料不能倒填旧本，续编或修订须有独立来源版本。对本稿的已成书传本，止笔 → 成书 → 相应渠道可传播 → 角色获知 → 查询水位须依序不倒退（允许同刻）；覆盖区间须能按锁定历法解释，错误纪年仍留在说法层。
- **知识校验**：成书不晚于获知只是必要条件；还须有合法渠道与实际接触依据。初始知识引用必须存在于对应传本，获知时间不晚于初始时刻，并明确所掌握条目或范围，不能由职业或渠道资格自动赋予整部史料。
- **视图**：历史条目与运行事件同表，靠来源标记区分，统一走认知接口按角色过滤；不设第二条读取路径。
- **补算与恢复**：补算不重写已固化历史；回填、展开及获知分别沿用稳定身份和幂等规则，重启不重抽、不重复消费。分叉 / 导出保留必要来源与固化产物；异步结果沿用既有水位、运行世代与回滚失效规则。

## 七、初期口径（临时，预期修改）

- 载体：**1 部官修 + 1 部非官修**；仅用于跑通链路。
- 跨度：当前纪年往前 2–4 个时代（百年级），刻意填不满。
- 条目量：10² 量级；「一句 : 段」≈ 9 : 1。

【缺口】体裁清单、载体数量、跨度与分档参数均为起步口径，**不冻结**，预期在后续版本修改。本页固定模型与约束，不固定规模；不承诺每卷都填满或每件事都配齐相反说法。

## 九、行为验收（待实现后执行）

1. **回填自洽**：回填不推翻已确认的历史、当前局势与角色背景；无法满足约束时创建失败或保留合法留白，不暗改锚点。初始知识引用不存在时不能创建实例。
2. **历史不重演**：历史后果和持续影响与初始状态一致；启动、重启、导入不重复执行历史效果，不给角色批量补发百年前事件。
3. **认知有来源**：读不同传本的角色可持相反观点；未接触来源者不能获知。后台展开不自动扩大任何角色的已知范围。
4. **真假分层**：完全虚构的指控可存在于普通史料并影响角色判断，但不会让指控内容成为实情或直接执行其所述效果。
5. **展开单调**：不同提问顺序、重复展开及分叉后的查询不改变既定事实与共同传本；不能从一句含糊记载临场补出未经确定的死因或责任人。
6. **回滚隔离**：回到获知之前，展开缓存、引用记录与派生记忆都不能让角色继续引用后来读到的内容；迟到任务不能恢复已撤销的获知。
7. **缺载与时间**：尚未生成不能冒充缺载，缺载不能直接当作删改证据；错记年代与相对年代不会改变事件实际时刻，也不会随查询悄悄改写原文。
