# 史料与历史生成（设计草案·审阅稿）

> 状态：审阅稿，尚未实现。内容并入 SPEC 后删除本文件。
> 归属：模型与校验 → `WORLD_SETTING_SPEC.md` / `EVENT_ENGINE_SPEC.md`；时刻与视图 → `WORLD_RUNTIME_SPEC.md`；角色引用 → `CHARACTER_CARD_SPEC.md`（「初始知识」已有钩子）。
> 来源：2026-09-19 讨论；五条决策已由用户确认（见附录）。

## 一、模型

**史书 = 公共叙事层的一种体裁 + 一个来源；历史数据是事件记录，史书是它的投影。**

不新建「历史数据结构」，不建立第二份真值：实情在事件骨架，史书条目是说法——`EVENT_ENGINE_SPEC.md` §二的说法集合里本来就有「来源渠道」字段。

## 二、对象

| 对象 | 内容 | 归属 |
|---|---|---|
| 事件（回填） | 纪年、主体、一句话事实、影响；与运行期事件**同表** | 事件模型 |
| 条目 | 事件在史料里的表述：体裁、措辞 | 说法（来源 = 载体） |
| 载体（传本） | 名称、编者、成书时刻、覆盖区间、体裁与立场 | 实体（物件）+ 来源渠道 |
| 体裁 | 官修编年 / 地方志 / 野史 / 碑刻 / 创世记述……（清单不冻结） | 生成侧文风 + 选择性规则 |

- 同一作品的不同传本（官修本 / 民间残本）**不建血缘层级**：关系由「同一事件标识 + 不同来源」自然可见——官方缺载、民间有载，就是改写的样子。
- **缺载是合法形态**：不需要为每个来源补齐每个事件；缺什么也是信息。

## 三、编者（两分）

- **古史书**：编者是可读的历史人物（名字、年代、立场），**不作为世界实体**、不可指涉、不参与运行。
- **近史书**：编者**作为实体**，可被引用、可被事件影响、可被用户在世界里问到。

【缺口】分界按世界包声明的年代阈值划定；阈值与「编者实体化」的完整校验（在世区间 vs 成书时刻）不在首版冻结，见 §六。

## 四、对抗性叙事（说法层的生成来源）

同一事件出现两种说法是**常态**，不是例外。三个基本型：

1. **同源异文**：抄写讹误、年代记混。
2. **立场改写**：上位不光彩 → 官方本改写；对敌人抹黑 → 敌我两说；为尊者讳 → 缺载。
3. **残本流失**：官方本改写后，只有民间残本保留旧记载。

- 神话 / 创世记述也是史料，且是唯一允许整体**不为真**的史料（它本就落在公共叙事层，无需新机制）。
- 真相只在实情层；角色相信哪一说，由她接触到的来源决定（确信度不等于真伪，既有规则）。

## 五、生成次序与分档

1. **骨架回填**（实例创建期；确定性，几乎不花 LLM）：按时代与大事抽样产出条目骨架；独立预算，不占运行期每日密度。
2. **一档文本**（创建期；按卷批量编纂）：十年一卷、10–20 条一次调用，全量产出「一句话」级文本，一次固化；批量顺带保证文风统一。
3. **二三档展开**（惰性）：被追问、被引用或成为剧情支点时展开为段 / 本末，展开后固化。

**「只细化、不矛盾」的含义**：展开以**新增记录**表达（沿用「事件与最初文本写入后不可原地改写，后续以新记录关联」的原规则），只允许让已有条目更具体，不允许推翻。它**不约束不同说法之间的互相矛盾**——那是设计想要的。

## 六、时间、校验与视图

- **时间**：世界秒排序是唯一时间基元；史料文本内的年代写法（「开元十七年」/「三百年前」）归体裁。
- **止笔**：每部载体有止笔时刻，之后的事不记载——近事只能靠渠道与经历。远近分工由此成立。
- **校验**：引用者获知时刻 ≥ 成书时刻；覆盖区间在世界历法内；角色卡初始知识引用的说法必须存在于其来源载体。
- **视图**：历史条目与运行事件同表，靠来源标记区分，统一走认知接口按角色过滤；不设第二条读取路径。
- **补算**不触碰已固化历史；回填与惰性展开不因重启重复。

## 七、初期口径（临时，预期修改）

- 载体：**1 部官修 + 1 部非官修**；仅用于跑通链路。
- 跨度：当前纪年往前 2–4 个时代（百年级），刻意填不满。
- 条目量：10² 量级；「一句 : 段」≈ 9 : 1。

【缺口】以上四项**不冻结**：体裁清单、载体数量、跨度与分档参数都预期在后续版本修改。本页只固定模型与约束，不固定规模。

## 八、残余（实现时标定）

- 各体裁的选择性规则与措辞提示词；批量编纂的分卷尺寸。
- 惰性展开的触发条件与预算。
- 编者实体化的年龄 / 在世校验如何表达。

## 附录：决策记录（2026-09-19）

1. 体裁组合与载体数量先按起步方案，但文档必须留下缺口标记，注明仅为初期跑通、后续需要修改。
2. 编者两分：一部分古史书的编者是历史人物但不作为世界实体；较近的一部分新史书编者作为实体。
3. 神话 / 创世计入史料；官方改写（上位不光彩）与民间残本是既有现象，需被建模。
4. 历史条目与运行事件同表不同视图。
5. 对同一段历史存在两种说法（含对敌人的抹黑）是合理且需要的。
