# UI 改进记录

> 基于 USER_INTERFACE_DESIGN.md 的 29 条可用性原则,针对**首次接触 AI 应用、不熟电脑操作**的用户画像进行的最小化改进。

## 改动原则

- **不新建设计文档**:现有三份文档已定稿且完整,问题在执行细节
- **最小化 diff**:只改文案、样式、少量交互提示
- **不重构**:不动底层逻辑、不增加新组件框架

## 已修改文件

### 1. `home.ts` — 首页

**原则应用**:#3 减少认知负荷、#1 符合心智模型、#13 视觉层级

| 改动 | 原因 |
|------|------|
| "先连接 AI" → "第一步:连接 AI" | 明确步骤顺序,降低"下一步是什么"的认知成本 |
| "这个程序本身不做生成:它调用你配置的 AI 服务" → "这个程序调用你提供的 AI 服务" | 删减冗余解释,15 字内完成核心信息传达 |
| "先整理素材(稍后配置)" → "先看看样例,稍后再配置" | 新手更关心"能不能马上试用",而非"整理素材" |
| 任务卡加 emoji(💬/✍️/🎲) | 增强示能性(#12),让卡片更像可点击对象 |
| 任务卡文案压缩(两句 → 一句) | "选一个角色,和她对话"比"选一个世界和角色,和生活在其中的人对话"减少 40% 字数 |
| 删除"检查"行 | 技术诊断信息移到"帮助与诊断",首页只保留用户关心的"世界数"和"AI 配置状态" |
| "世界设定" → "设定" | 术语简化 |

### 4. `style-accessibility.css` — 新增样式文件

**原则应用**:#23 触控目标、#20 不只靠颜色、#14 对比、#21 焦点可见

```css
/* 主按钮 44px 高(符合触控目标最小 44×44pt) */
.u-btn-primary { min-height: 44px; font-weight: 500; }

/* 状态用图标前缀,不只靠颜色 */
.u-chip::before { content: "●"; }
.u-chip[data-kind="ok"]::before { content: "✓"; color: #2e7d32; }

/* 次要文字 #666 → #555 (对比度 5.74:1,达标 WCAG AA) */
.u-note { color: #555; }

/* 焦点可见:2px 蓝描边 */
*:focus-visible { outline: 2px solid #1976d2; outline-offset: 2px; }
```

# 第二轮：真壳实测（2026-09-24）

按「完全不了解项目的用户」的方式跑真壳（截图 + 鼠标键盘，不读 DOM），复现到的问题与处置。
明细与读数在 `.hermes/uat/FINDINGS.md`（本地证据，不入库）。

## 一、页面内跳转：入口带的下标没人认

现象：入口按钮承诺的地方和实际落到的地方不一致。

| 从哪里 | 按钮说去哪 | 实际 | 处置 |
|---|---|---|---|
| 首页 / 联络 / 写作 / 跑团 / 世界与素材 | 从样例世界开始 | 首次设置第 1 步「本机检查」，要重走一遍 | 向导认 `sub`：`sample` → 「准备材料」；但本机检查或 AI 还没过时仍从第一步走 |
| 联络页 | 时间线与版本 | 世界列表 | 世界与素材认 `timeline` → 直接开世界详情（时间线就在里面） |
| 首页 | 导入已有内容 | 世界列表 | 认 `import` → 直接开选文件 |
| 跑团页 | 打开设置里的扩展页 | 设置页顶部（那一页很长） | 认 `extensions` → 滚到扩展那一节 |

规则：**入口给的下标，目标页必须认；认不出来的要落到一个说得通的位置，不能静默落到上一页的默认态。**

## 二、并列选项没有「当前在哪一格」

现象：写作页的四格（大纲 / 当前素材 / 推进建议 / 文字草稿）切换后，四格长得一模一样；
世界与素材切到「世界设定 / 角色卡」后，高亮还留在「我的世界」；创建向导的步骤条同样没有当前格。

原因：高亮类名 `.u-nav-active` 的样式只写在 `.u-nav-btn.u-nav-active` 上，而 `.u-nav-btn` 随方案 B 的侧栏一起退场了。

处置：补一条通用的当前格样式（黑底反白 + 加粗，hover 不回退），并让写作分区、创建向导步骤、世界与素材分栏各自维护「当前格」状态 + `aria-current`。

规则：**并列选项切换子页面时，当前那一格必须有肉眼可见的区别，并且要能被读屏识别（`aria-current`）。**

## 三、顶栏返回：写清去处，按层级回

现象：左上角只有一个应用 emoji，点下去究竟回哪儿看不出来；从设置 / 帮助 / 世界管理回不到刚才的应用。

处置：
- 应用三页（联络 / 写作 / 跑团）与首页 → 「← 返回选择应用」；
- 设置 / 帮助与诊断 / 世界管理 / 首次设置 / 创建世界 → 「← 返回辅助写作」这类写明去处的键，点了回应用根；
- [⋯] 菜单补「首页」（方案 B 删侧栏后它失去了唯一入口）；
- 启动器「刚选过就不打扰」只作用于启动时的自动弹窗——用户自己点返回是明确意图，不能被它吞掉。

## 四、首次设置「选择第一件事」与实际能力不符

现象：辅助写作 / 进行跑团 两张卡写「这条路径正在实现中…」并置灰「暂未开放」，而启动器里这两个应用明明可选（U3/U4 已落地）。

处置：三条路都可用，动作名分别是「开始联络 / 开始写作 / 开始跑团」；选哪条就记下应用模式，建完世界直接落到那个应用（以前向导不设应用模式，落点取决于有没有点过启动器）。

## 验证

- `tsc -p tsconfig.json --noEmit`：通过
- 真壳探针：`_probe_ui_u1 / u2 / u3 / u4`（方案 B 之后 `nav.u-nav` 侧栏没了，这几支的导航入口统一改走新的 `_ui_nav_common.py`：⋯ 菜单选页 / 启动器选应用）+ 新增 `_probe_ui_nav.py`（本次四类修复的回归：跳步、分栏高亮、返回层级、5 秒守卫、extensions 定位）

# 第三轮：把「文字说不清」的地方画出来（2026-09-24）

口径：人理解一个不清楚的东西，看图比读字快。所以把**关系、比例、顺序、整体状态**这四类
「要读三遍才建立得起来」的信息从文字里拿出来画；一个词或一个数值就说清楚的，不动。

新增 `desktop/src/user/graphics.ts`（DOM + SVG，零依赖）：流程轨 / 比例条 / 计量条 / 分支图 /
检查清单 + 状态点。三条纪律：图是**补充**不是替代（旁边保留可读文字，读屏不吃亏）；
颜色只做强调，含义写在文字图例或标题里；**不画空数据**（算不出比例就不画，按原文案说「还没有…」）。

| 页面 | 原来 | 现在 |
|---|---|---|
| 世界详情 · 版本记录 | 一列「时间｜世界进度｜类型｜备注」 | **分支图**：一条时间线一条泳道，提交是圆点，虚线是「这条线从哪个版本分出来」；点圆点会滚到下面那一行 |
| 世界详情 · 时间线 | 世界速度：一个数字 | 数字旁常驻「现实 1 分钟 ≈ 世界 X」，跟着输入变 |
| 世界详情 · 尝试世界变化 | 效果一行「种类 → 对象：值（持续到何时）」+ 一句「确认后另开一条新线」 | 变化拆成「种类 · 作用到 · 变成什么 · 持续」；下面是三步轨：草案已生成 → 等你确认 → 新线（暂停） |
| 辅助写作 · 大纲 | 六张卡的「（N 条）」+ 每条的「未开始 / 已达成 / 已偏离」标签 | 概览一条比例条（带数值图例）+ 每个分区一条细条 |
| 辅助写作 · 检查结果 | 「缺口：…」「偏离：…」两段列表 | 顶上三个计数（缺口 / 偏离 / 可用依据），原文列表照旧 |
| 辅助写作 · 推进建议 | 依据三条夹在事实表里，「（缺）」是小字 | 每条依据一个 ✓/✗ + 原文 |
| 跑团 · 进行中 | 「阶段 needs_input / resolved」这类内部词 | 四步轨：写下行动 → 确认卡齐备 → 规则裁定 → 写入世界；当前那格反白；通知文案也改成人话 |
| 跑团 · 过去结果 | 「结果顺序固定：…」一句散文 | 同一顺序画成四节点链 |
| 角色联络 · 已讲过的线索 | 只有条目 + 「另有 N 件她还没讲出口」 | 顶上一条比例条（已经讲出口 / 还没讲出口），条目照旧 |
| 设置 · 用量 | 只有一行「bucket｜20500」 | 计量条：这个世界今天用掉 / 各条时间线 / 按任务（人话任务名 + 调用次数） |
| 本机检查与连接测试（首次设置 / 帮助 / 设置） | 「通过：…」「需要处理：…」 | ✓/✗ 逐项 |
| 创建世界 · 分区目录 | 「N 条」 | 「N 条 · 已锁 x」+ 一条锁定进度细条 + 有校验问题的区标「N 处待处理」 |
| 从旧的开发目录迁移 | 「正在迁移（复制 → 校验 → 启用）…」 | 三步轨：检查旧目录 → 复制到暂存 → 校验并启用 |

## 一处顺带修掉的真 bug

「已讲过的线索」一直只显示「另有 N 件她还没讲出口」：界面按 `stage` / `text` 取字段，
而故事图谱给的是 `kind` / `label`——过滤条件恒为空，她**讲过的内容一条都不列**（面板等于半废）。
按图谱的字段取回，并在探针里锁上「界面条数 = 库里 spoken 条数、正文不是占位文案」。

## 有意没画的

- 位置与日志、备份列表、版本号一类**键值型信息**：没有结构，画出来只是换一种罗列；
- 世界详情的角色清单、扩展与规则登记：行状状态列表，图形不增加信息。
