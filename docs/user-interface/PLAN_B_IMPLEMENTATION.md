# 方案 B 完整实现记录

## 改动文件

1. **app.ts**
   - 删除 `NAV` 和 `NAV_FOOT` 导航数组
   - `build()` 删除左侧边栏(`u-side`),改用 `u-frame-focused` 全宽布局
   - `renderTop()` 改为 emoji 返回按钮 + [⋯] 更多菜单

   - 全屏布局:`u-frame-focused` 占满视口

4. **index.html**
   - 引入 `style-focused.css`

## 工作原理

```
启动 → 选择器弹窗 → 选 Chat/Writer/GM → 全屏专注模式
                                         ↓
                          左上角 emoji 按钮 → 返回选择器
                          右上角 [⋯] → 设置/帮助/世界管理
```
