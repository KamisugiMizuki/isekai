## 工作原理

```
启动 → 选择器弹窗 → 选 Chat/Writer/GM → 全屏专注模式
                                         ↓
                          左上角「← 返回选择应用」→ 返回选择器
                          右上角 [⋯] → 首页/设置/帮助与诊断/世界管理
```

2026-09-24 修订（真壳实测后）：

- 左上角按钮不再是一个看不出用途的 emoji，而是写清楚去处的返回键：
  **应用三页（联络 / 写作 / 跑团）与首页**的上一级是选择器（「← 返回选择应用」）；
  **设置 / 帮助与诊断 / 世界管理 / 首次设置 / 创建世界**挂在当前应用下（「← 返回辅助写作」，点它回应用根）。
- [⋯] 菜单补「首页」：方案 B 删掉侧栏后首页失去了唯一入口，而「未完成内容 / 本机状态」都在那一页。
- 启动器里「刚选过（<5 秒）不打扰」的守卫只作用于**启动时的自动弹窗**：用户自己点返回是明确意图，不能被它吞掉。

## 用户体验变化

| 场景 | 方案 A(原导航栏) | 方案 B(完整实现) |
