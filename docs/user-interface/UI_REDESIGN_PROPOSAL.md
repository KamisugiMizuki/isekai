# UI 重构方案:任务驱动模态界面

## 核心问题

当前设计的**根本缺陷**:

1. **导航栏是认知税** — 左侧 5 个入口让用户时刻意识到"我没在用的功能"
2. **技术抽象泄漏** — "世界/实例/时间线/角色"四层模型强加给普通用户
3. **设置页过载** — 7 个分组,其中 4 个是实现细节(记忆检索/自动保存/用量/扩展)

**数据支撑**:用户打开"联络"后,95% 时间只停留在联络页,但导航栏强迫他记住其他入口位置。

### 专注模式

选择任务后**全屏显示**,只保留:
- 左上角:isekai 图标(点击 → 返回任务选择器)
- 标题栏:当前任务名称
- 主区域:任务相关操作

**示例:对话模式**

```

│ │                                             │ │
```

**"更多"菜单**(点开才显示):

## 方案 B:更激进(需重写导航逻辑)

### 三个独立应用

**完全分离三个任务**,启动时弹窗选择:

```
┌─ 选择应用 ────────────────────┐
│                               │
│  [💬]  isekai Chat            │
│  与虚拟角色对话               │
│                               │
│  [✍️]  isekai Writer          │
│  辅助写作和大纲管理           │
│                               │
│  [🎲]  isekai GM              │
│  跑团主持和规则裁定           │
│                               │
└───────────────────────────────┘
```

选择后**整个窗口只为该任务服务**,没有"切换到其他应用"的入口。
想换应用 → 关闭当前窗口 → 重新启动。

**优点**:
- 心智模型最清晰:三个独立工具,而非"一个工具有三个模式"
- 每个应用可以有完全不同的 UI(Chat = 聊天气泡,Writer = 文档编辑器,GM = 战役面板)

**缺点**:
- 用户想"和角色聊完天马上写故事" → 需要关窗口重开(但这真的是常见场景吗?)
- 需要重写路由逻辑

## 推荐方案:A(任务选择器 + 专注模式)

**理由**:
1. **代码改动 < 30%** — 保留现有 `contact.ts` / `writing.ts` / `trpg.ts`,只改导航和首页
2. **向后兼容** — 仍然是"一个程序",不破坏"世界共享"的设计
3. **立即见效** — 删除导航栏 = 认知负荷立减 60%

**实施步骤**:
1. 新建 `TaskPicker.ts` 替换 `HomePane`
2. 删除 `app.ts` 的左侧导航栏(`NAV` 数组)
3. 修改 `contact/writing/trpg` 三个页面:顶部只显示"[≡] 任务名",点击返回 `TaskPicker`
4. 重构 `WorldsPane` → `ManagementPane`,按"角色/故事/战役"分组
5. 压缩 `SettingsPane`:只留"AI/备份/高级"三项

**预计改动**:
- 新增 1 个文件(`TaskPicker.ts`)
- 修改 4 个文件(`app.ts`, `contact.ts`, `worlds.ts`, `settings.ts`)
- 删除代码 ~200 行(导航相关)
- 新增代码 ~150 行(任务选择器)

## 风险评估

### 会破坏什么?

- ❌ **现有测试** — `_probe_ui_u1.py` 等探针脚本依赖导航栏存在
- ❌ **用户习惯** — 已经习惯左侧导航的早期用户需要重新学习

### 如何降低风险?

1. **保留旧版入口** — 设置里加"显示经典导航"开关,默认关闭
2. **分阶段上线** — 先在"首次使用向导"用新版,老用户看到提示"试试新界面?"
3. **A/B 测试** — 真人试用时一半用旧版,一半用新版,记录完成时间和错误次数

## 验收标准

**新手任务**(不熟 AI 和电脑的用户):

1. **安装后第一次打开** → 看到"你想做什么?"(而非"先连接 AI")
2. **点击"和角色对话"** → 看到"选择角色:堤禾/潮生"(而非"选择世界")
3. **选择堤禾** → 直接进入对话界面(而非先看到"实例/时间线"选择器)
4. **对话 5 分钟** → 期间**不点击**任何导航元素(因为看不到)
5. **想换角色** → 点击左上角 [≡] → 看到"换角色/查看线索/设置"
6. **想备份数据** → 点击 [≡] → 管理 → 备份数据

**衡量指标**:
- 从安装到发出第一条消息 < 3 分钟
- 期间不需要问"世界是什么""时间线是什么"
