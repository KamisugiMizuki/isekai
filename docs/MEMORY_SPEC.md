# 角色记忆（MEMORY_SPEC）

> 上游总设计：[`DESIGN.md`](DESIGN.md)（总纲） · 本文为「角色记忆」子系统设计文档
> 来源：2026-09-19 深化轮（参考 veranima 记忆架构重写，以**角色经历**为中心；召回 = 混合（全文 + 向量），向量化走远程 API）。
> 定位：世界运行层的子系统——存储与版本化随角色状态（`WORLD_RUNTIME_SPEC.md` §六）；本文件承载原 `SESSION_CORE_SPEC.md` §六的细则。

## 一、定位与中心

- 记忆的主语是**角色**；组织中心是**角色经历**。
- 用户对话是其中一类经历（「与联络者的交谈」），与其他经历同等记录，无特殊加权。
- 目标：让她记得她经历过的世界、她做过的事、她与联络者的来往。
- **遗忘与不确定是合法状态**：记忆会衰减、会模糊、会带保留地表述——这不是缺陷，是拟真面。

## 二、数据域（三层）

| 域 | 内容 | 写入时机 |
|---|---|---|
| **对话原文** | 与联络者的往来消息（逐条） | 每轮 |
| **经历** | 角色侧事实：她做过 / 遇到 / 经历的事（挂世界时间与事件引用） | 生活线推进、事件发生时 |
| **规范记忆** | 从上述两者提取的可召回条目（带强度 / 置信 / 作用域） | 提取策略见 §四 |

## 三、规范记忆条目模型

| 字段 | 说明 |
|---|---|
| 文本 | 一到两句话的条目（入库前蒸馏，见 §四） |
| 来源引用 | 对话消息 id / 事件 id / 经历 id |
| 类型 | 事实 ｜ 片段 ｜ 承诺 ｜ 印象 |
| 强度 | `[0,1]`，召回升、衰减降（见 §六） |
| 置信 | `[0,1]`，她的确定程度——从**说法层**来的内容天然低置信（「听说」） |
| 世界时间 | 记忆发生 / 记录的世界时刻（历法） |
| 作用域 | 世界实例 + 时间线（随角色状态 diff / 提交 / 回滚） |
| 状态 | 活跃 ｜ 衰减中 ｜ 归档 |

## 四、写入（什么值得记）

- **提取时机（参考 veranima：一轮固定顺序）**：对话轮结束后按固定顺序提取候选；经历在生活线 / 事件推进时产生候选。
- **值得记的内容（角色中心）**：
  - 她的经历与决定；
  - 她与联络者交谈中有分量的部分；
  - 她获知的信息——**含低置信传闻与说法**（双轨内容进入记忆时记「听说」）。
- **不值得记**：寒暄、无内容往来、纯噪声——由提取判断点过滤（低成本 LLM 判断 + 规则兜底；按判断点设计哲学，失败回退保守保留）。
- **粒度闸**：入库前蒸馏为一句到两句话；不整段塞原文。
- **去重与合并**：相似条目合并（同事实多来源 → 合并并提升强度）。
- 记忆是黑箱：用户不可浏览记忆内容（与「世界实例黑箱」一致）。

## 五、召回（混合）

**流程（参考 veranima：查询规划 → 候选 → 排序 → 简报）**：

1. **查询构造**：从当前消息 + 会话上下文生成查询，带**时间锚点**（当前世界时间）。
2. **候选生成**：双路——
   - 全文检索（词面）；
   - 向量检索（**远程 embedding API**，随 LLM key 体系，不增额外依赖）。
3. **排序**：相关性 × 强度 × 世界时间邻近度；同分取条目 id 序（确定性）。
4. **简报（brief）**：打包为「她想到的事」注入生成链路（措辞从角色视角；预算在实现时标定）。

**纪律**：

- 未嵌入 / 嵌入失败的条目 → 退化为全文召回（fail-open，不阻断）。
- **置信驱动表达**：低置信记忆带「听说 / 记不清」；归档记忆被唤起时带模糊表述。
- 简报只进生成上下文，不外泄（不展示给用户）。

## 六、衰减与整理

- **强度衰减**：按**世界时间**推进（受倍率影响——她的「日」）；被召回 / 被提及 → 强度上升（有上限）。
- **归档**：强度低于阈值 → 进入归档（不主动召回，可被强相关检索唤起）。
- **整理（Curator）**：周期性任务——合并同类、压缩冗长、评估归档保留；**挂她的作息节律**（如睡眠时段）执行，不打断她的白天。
- 整理只动结构与强度，**不改写事实**。

## 七、作用域与版本

- 记忆是**角色状态的一部分**：随时间线隔离、随 diff 复制、随提交快照、随回滚截断。
- 跨时间线不共享；实例内自包含；随世界实例导出。

## 八、实施分期

1. **基础**：对话原文 + 经历 + 规范记忆（简单提取）+ 混合召回（全文先行、向量接入）+ 简报注入。
2. **衰减 / 强化 / 归档 / 整理（Curator）**。
3. **细化**：去重合并策略、冲突版本链（后期）、深度整合（可选）。

## 九、与其它模块的接口

| 对方模块 | 接口面 |
|---|---|
| 会话核心层 | 写入（轮后提取）；召回（生成链路注入）；置信与表达的对应 |
| 世界运行层 | 角色状态载体（diff / 提交 / 回滚）；生活线与事件产生经历 |
| 世界事件引擎 | 事件 → 经历与记忆候选（说法层 → 低置信记忆） |
| 世界设定层 | 双轨内容（说法来源）；实例生命周期 |

## 十、待模块设计项（残余）

- 规范记忆的存储 schema 与索引（全文 + 向量字段）。
- 提取判断点的提示词与阈值。
- 排序公式参数与简报字数预算。
- Curator 的触发条件与整理粒度。
