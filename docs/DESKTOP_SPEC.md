## 一、职责与边界

**职责**：聊天 / 管理 / 设置界面、核心进程监督、受信连接、托盘与退出、触发恢复。

- 壳不实现世界、会话、记忆或补算业务，只调用核心的统一契约。
- 用户可见：往来对话、当前查看的激活线时钟、运行 / 连接状态，以及实例 / 时间线 / 提交的必要管理元数据。
- 不展示：实情、事件日志、角色状态 / 活动面板、性格数值、认知条目、记忆内容、内部 diff。
- 聊天使用 UMP；管理操作走受信管理接口。两者可在同一窗口共存，但不能把管理权限发给普通通道。

## 二、进程模型与接线

1. 壳启动，确认同一数据目录只有一个核心写入者；重复启动复用 / 唤起已有应用，不再启动第二个写库进程。
2. 通过受控入口拉起 Python 核心，等待有限时间的就绪响应；响应提供本地 WS 端点与核心签发的一次性引导凭据。
3. 聊天完成认证与 UMP 握手，管理面取得独立权限；不能仅凭端口开放就显示可用。
- 核心恢复本地状态并按线补算，壳显示正常 / 追赶中 / 失败；未就绪线不能发起新生成或导出半恢复状态。
- 打开已有实例时先完成数据格式与运行规则能力检查；可兼容实例沿原规则恢复，不兼容或迁移失败则保持原数据只读 / 冻结并提示兼容版本或可信转换，不静默用新规则补算。

- 核心崩溃给明确错误和重启入口，不无限自动重启；重连身份与已接收请求保留。
- 核心启动结果按 `ready`、`catching_up`、`compatibility_blocked`、`persistence_blocked`、`failed` 区分；壳只消费核心结果，不根据端口、旧缓存或 UI 自己推断可用。非 `ready` 状态禁止新对话提交，历史读取范围由核心明确返回。
- 一次性凭据消费后，重连经受信壳重新取连接凭据；令牌与 API Key 不进入 URL、日志、第三方插件环境或导出件。
- 核心 / 插件按所属进程树管理；壳异常退出也要避免孤儿写入者，不能靠杀任意占端口进程代替所有权检查。
- 等待超时给启动阶段与日志位置等技术诊断，不暴露世界内部内容。
- 核心进入持续写盘错误态时，壳显示存储不可用并停止新的不可持久化工作；不得把未固化回复显示为成功，不得自动删除历史或备份腾空间。恢复写入后由核心从最后完整水位继续。
- 高倍率追赶受限时显示追赶状态与管理动作入口；壳不把目标时刻当成已完成水位，不允许从未完成状态发起普通对话或完整导出。

## 三、界面结构（单窗口侧栏式）

```text
侧栏：会话 / 世界 / 时间线
内容区：聊天 / 管理 / 设置
```

### 3.1 聊天面

- 消息流、多分段、时间戳；Enter 发送、Shift+Enter 换行；接受、生成、失败、投递未知等状态区分清楚。
- 顶栏显示当前实例 / 角色 / 时间线名称；**仅当前查看且已激活的线显示世界时钟**。冻结线提示需激活，不自动改世界状态。
- 消息时间戳默认标注现实时间；世界时刻若显示须明确标记，不能混用同一时间标签。
- 历史按当前会话分页加载，核心持久记录为真值；重连后补读，回滚 / 重绑后清空旧版本缓存再加载。
- 切换角色、世界、时间线是在选择另一会话，不迁移历史；多个激活线可以后台推进，切换视图不冻结它们。
- 生成 / 投递失败的重试按协议恢复对应阶段；投递未知时提示可能重复，不重新生成一份回复。
- 披露沿已有对话选择明确片段与接收角色确认；不提供其他角色记忆或世界实情浏览器。
- 初次联络在用户打开会话时到达；状态区分待生成 / 生成中 / 已生成未投递，不显示内部触发细节。
- 睡眠期等待显示为正常处理中，不暴露内部睡眠状态，也不承诺总送达时长。
- 桌面提醒只作为已固化主动消息的入口，不作为第二份历史；点击后由受信管理面定位原实例 / 时间线 / 角色会话。目标已失效时显示技术错误，不自动激活冻结线或改投其他角色；系统通知不可用时用户仍可从历史读取。

### 3.2 管理面

| 区域 | 允许的操作与信息 |
|---|---|
| 实例 | 名称 / 原始包来源 / 创建时间；创建、整体导入导出、全局唯一重命名、删除 |
| 角色 | 选择目标时间线 → 创建 / 审定补卡 → 确认预算与加入语义 → 原子提交；失败可续作，不显示内部角色状态 |
| 创建 | 选世界包 → 装配全部角色卡并联合校验 → 审定 → 命名 → 原子创建 → 用户选择是否激活 |
| 时间线 | 名称、来源提交关系、状态；从提交创建、激活 / 冻结、归档、删除、选择查看 |
| 世界修改 | 用户事件意图 → 不泄密的可执行草案 → 确认来源点 → 创建新线；普通聊天不触发此操作 |
| 版本 | 手动提交、回滚；列表仅标识、时间、用户备注，不显示自动剧情摘要或内部差异 |
| 时钟 | 当前查看激活线的历法时间及倍率调整；显示待生效结果，不在前端独立算另一套钟 |
| 世界包 | 文件选择、有限字段表单 / 对话式生成与修改；修改模板不更新既有实例 |
| 通道（插件阶段） | 登记、启停、失败 / 手动重启、thread 绑定与主动目标；允许停用内建聊天但保留管理面 |

- 回滚 / 删除需二次确认，明确范围、失去的进展及外部平台消息不能保证撤销。
- 回滚前要保留当前进展，提供「先创建保留时间线或整体导出」指引，不声称仅手动提交就一定保住被覆盖的未来。
- 导入明确提示创建独立新副本，全部线默认冻结；不覆盖现有实例、不继承源端通道或补算运输时间。
- 原生文件选择 / 保存负责路径授权；非法文件与版本错误由共享校验器处理，不让前端自行放宽。
- 首次启动无可用世界包时提供三个入口：AI 生成 / 表单式 / 导入；导入须先区分世界包模板与实例导出件。没有 API Key 仍可手编、保存草稿或导入。
- 草稿：候选世界包与候选角色卡单独保存，允许未填完并标记未通过校验；关闭引导后可显式继续，「丢弃草稿」才删除。

### 3.3 设置面

| 组 | 项 |
|---|---|
| LLM | 服务地址、模型、API Key；UI 写入、读取打码 |
| 记忆向量化 | 独立服务地址 / 模型 / Key，或明确选择复用聊天凭据；说明用于远程语义召回，未配置可全文降级 |
| 提交 | 自动提交开关、现实间隔、事件阈值；关闭不影响状态日常持久化 |
| 世界 / 会话 | 世界包目录、激活数量上限、主动每日额度；倍率上限只读且仅开发者可配置 |
| 备份 | 立即备份、恢复备份、打开备份目录；目录、间隔、保留数；只显示时间、完整性与成功 / 失败 |
| 用量 | 生成与回填的预估确认与总调用上限；实际用量记录（调用次数与 token 量级），不猜价格、不做费用面板 |
| 外观 | 黑白极简主题，跟随系统明暗 |
| 关于 | 应用 / 数据格式版本、日志目录、脱敏诊断 |

- 日常用户可调项由 UI 保存到本地配置，不要求反复手编配置；凭据仅存本地受保护配置，默认不进入插件和实例包。
- 配置检查失败保留原值；错误提示不回显完整 Key。
- 首次配置远程服务说明会发送必要文本；不把「无云同步」误称为「全部计算都在本机」。
- 备份与恢复只提供入口与配置，由核心执行：备份复用一致水位与引用闭包；恢复是整套受管数据的灾难恢复，不是实例导入。整库备份包含确认世界包 / 草稿、实例登记、实例与时间线状态、会话 / 记忆 / 事件来源、去重作废记录、预算账本和必要版本元数据；不含 API Key、连接凭据、临时模型上下文、日志、设备路径或当前连接。恢复前停止所有写入者，校验暂存库后原子切换；切换使旧连接、绑定令牌和异步任务统一失效，重连必须重新握手与补读。
- 后台世界推进、生活计划、记忆提取、惰性展开和主动生成共享核心的调用预算；预算耗尽时显示待处理 / 降级，不阻止事实状态推进，也不以重试绕过上限。
- 生成模型设置显示当前模型与最近一次变更时间；变更不重写历史文本。若模型或规则能力不再支持旧实例，按兼容性阻断处理，不以新模型静默继续旧规则。

## 四、视觉与可访问性

- 黑白语义色板，明暗两套；无衬线、细描边与圆角，无装饰性渐变。点缀色只辅助操作状态，不新增内部数据看板。
- 键盘可完成选择、发送、确认与取消；焦点可见、控件有名称，错误不能只靠颜色区分。
- 空实例、无会话、离线、追赶中与生成失败有明确空态 / 状态，不用假消息冒充角色发言。
- 长历史分页、长文本换行 / 分段、不挤坏输入区；输出作为文本安全渲染，不执行角色文本中的 HTML / 脚本。
- 具体 token 与控件尺寸在实现首版确定，不照搬其他项目整套 UI。

## 五、生命周期与补算

- 关闭窗口默认到托盘，核心继续运行；托盘提供显示主窗口 / 退出。
- **显式退出先保存再停进程**：停止接受新工作 → 核心持久化各线一致状态、推进水位、倍率与待生效命令 / 本机激活集合 → 确认退出 → 停止所属核心与插件进程树。
- 退出等待有上限；超时或异常终止从最后持久化水位恢复，不能只依赖正常退出回调才有存档。
- 本机退出 / 崩溃不会自动冻结逻辑上激活的线；再次启动由运行层补算这些线，冻结线不追赶。**导入新副本是另一种恢复语义**，不继承离线推进资格。
- 整库恢复不同于实例导入：它替换受管数据根，保留备份内的草稿、实例登记与控制记录；恢复后全部世界线先冻结，旧客户端 / 旧任务不能凭原令牌继续写入，用户明确激活后再按运行层规则恢复。
- 补算唯一规则在 `WORLD_RUNTIME_SPEC.md` §2.6：预算限制单批工作，不用摘要跳过事实效果。壳只展示追赶状态、提供管理入口，不自行实现另一套补算。
- 中断生成显示原请求的中断状态；已固化回复可恢复，旧主动消息不集中补发。
- 备份：运行期间定时检查，启动恢复后与显式退出前补做到期检查；失败不更新成功时间、不删除旧备份；新备份完整校验成功后才轮转；有界等待，退出不无限等。

## 六、错误与诊断

- 明确区分核心未就绪、某线追赶、模型失败、向量服务降级、通道失败与导入失败，不能全部变成「角色没回复」。
- 壳与核心日志分离，记录阶段、耗时、关联标识、错误码；默认不复制对话正文、实情、角色卡秘密、记忆或 prompt。
- 「打开日志目录」不是内部状态查看入口。诊断导出若以后提供仍须脱敏，不捆绑整个实例与配置。
- 恢复与重试按所属模块契约执行，不在 UI 偷偷重建世界或删除失败记录。

## 七、与其它模块的接口

| 模块 | 契约 |
|---|---|
| 通道插件层 | 官方 UMP 客户端、认证 / 重连、插件阶段的启停与绑定 |
| 会话核心 | 会话选择、历史分页、失败 / 投递状态及缓存失效 |
| 世界运行层 | 公开时钟、状态、激活 / 冻结、提交 / 回滚与补算 |
| 世界设定层 | 创作、实例创建、原子导入导出与版本错误 |
| 角色卡 | 创建前生成 / 审定；锁定实例内只有角色选择，无改卡入口 |

## 八、实施分期

- **阶段 0**：sidecar 监督、最小持久聊天、设置、托盘；管理面仅必要占位，不宣称真实世界创建完成。
- **阶段 1**：世界包 / 角色卡创作、真实实例创建与导入导出。
- **阶段 2–3**：时钟、倍率、激活冻结、补算状态及世界源主动消息。
- **阶段 4**：多时间线、完整版本操作与用户引入事件。
- **阶段 5**：多角色选择与披露；插件 UI 随外部通道需求启用。

## 九、待模块设计项（残余）

- 视觉 token、托盘图标、管理接口的具体形状。
- 进程监督与凭据传递的系统实现；启动 / 退出超时及恢复提示。
- 固定硬件、模型与负载下的性能基线数值；指标包含启动就绪、完整回复、补算吞吐、常驻内存、长历史分页和长期运行，不用首字延迟替代非流式 UMP 的完整回复延迟。
- 不新增世界内部浏览器、全量配置编辑器、云同步或桌宠窗口。
- 【待定】是否随应用发行一部样例世界包（首次体验更直观 vs 内容维护成本与「这是别人的世界」的混淆）。

## 十、行为验收

1. 双重启动不产生两个写库核心；关闭到托盘仍推进，显式退出或异常终止后无所属孤儿写入者。
2. 启动认证失败 / 超时有明确结果，不只凭端口显示就绪；凭据不泄入日志或插件。
3. 冻结线只读历史；查看切换不影响激活集合；时钟只显示当前查看的激活线。
4. 回滚使旧缓存与旧生成失效，确认文案说明破坏性；仅手动提交不被误称备份。
5. 创建前能审定全部角色卡；导入是独立冻结副本，失败不留半实例。
6. UI、管理响应与日志无实情 / 事件 / 性格 / 记忆明细；角色文本不能执行脚本。
7. 网络断线后的重试不重复生成或消费额度；embedding 失败时聊天显示可用的降级而非整体故障。
8. 键盘操作、空态、长历史 / 长文本与明暗模式均可用；内建聊天停用后管理入口保留。
9. 首次启动无包时可走三个入口；无 Key 可手编 / 存草稿 / 导入；关闭引导后可续作，丢弃草稿不损伤正式资产。
10. 备份失败不删除上一份；损坏不静默重建；恢复失败不覆盖现有库；恢复成功后全部线冻结、不补算旧间隔、不重发消息、不含凭据。
11. 生成 / 回填达到确认的调用上限时暂停且续作复用有效产物；用量记录不含对话正文、prompt、世界秘密或凭据。
12. 打开旧实例时兼容检查先于补算；不兼容或迁移失败不会覆盖原数据、静默换规则或显示正常运行。
13. 持续写盘失败时 UI 显示存储错误，未固化结果不成功投递；恢复写入后可继续，旧备份仍保留。
14. 后台任务共用调用预算；预算耗尽后事实推进、历史读取与普通对话按既定降级继续，派生任务可待处理，不重复生成。
15. 生成模型更换后既有回复、事件文本和记忆来源不被重生成；新的回复记录模型变更边界，旧实例规则不受模型默认值替换。
16. 性能验收使用固定环境与负载，完整回复延迟、启动就绪、补算吞吐、内存、长历史分页和长期运行均有记录；模型不可用时单独标记外部依赖失败。
17. 桌面提醒点击后打开固化消息所属的当前有效会话；目标被删除、归档、回滚或重绑时不改投其他会话、不激活冻结线，并显示管理错误；提醒不可用时历史仍可读取。
18. 追赶受限时目标水位不继续无限扩大；等待、降倍率、冻结分别遵守运行层顺序，未完成状态不会进入普通对话或完整导出。
19. 补卡可从管理面选择目标线并完成卡片审定、预算确认和原子提交；失败、取消或重试不留下角色定义、成员资格、加入事件或半条线。
20. 整库恢复停止全部写入者并原子切换；草稿、实例登记、预算与去重状态按备份恢复，旧连接 / 令牌 / 异步任务失效，恢复后所有线冻结且不自动发送旧消息。
