# 桌面壳（DESKTOP_SPEC）

> 上游总设计：[`DESIGN.md`](DESIGN.md)（总纲） · 本文为「桌面壳」模块设计文档
> 来源：2026-09-19 深化轮（决策：单窗口侧栏式；黑白极简视觉；**默认托盘常驻**，显式退出后下次启动补算）。
> 技术栈：Tauri 壳 + Python 核心（sidecar）。

## 一、职责与边界

**职责**：窗口与界面（聊天 / 管理 / 设置）、拉起与监督 Python 核心（sidecar）、端点与令牌下发、生命周期（托盘常驻、退出与补算触发）。

**非职责**：一切世界 / 会话 / 记忆逻辑在核心——**壳不实现业务**，壳 = 前端 + 进程监督。

**不变式**：

- 界面只呈现两类东西：① 对话内容（经 UMP）；② 管理操作入口（世界 / 时间线 / 版本 / 时钟 / 导入导出 / 设置）。
- **黑箱**：界面不得展示世界实例内部数据（事件日志、角色状态、记忆内容一律不可见）；用户可见的世界信息只有**世界时钟**与运行状态提示。
- 内建聊天窗口 = 通道客户端（UMP over 本地 WS），保持可拆为插件的形态（聊天逻辑不与管理面耦合）。

## 二、进程模型与接线

- 壳启动 → spawn Python 核心（sidecar）→ 核心就绪（本地回环 WS 端点 + 一次性令牌）→ 窗口连入并握手（UMP `hello`）。
- 监督：核心崩溃 → 壳提示 + 提供重启；显式退出 → 停止核心与全部插件进程。
- 就绪等待：壳等待核心就绪信号（端口就绪 / 握手成功），超时给出诊断（日志指引）。

## 三、界面结构（单窗口侧栏式）

```
┌──────────────┬──────────────────────────────────────┐
│ 左侧栏        │ 内容区（聊天 / 管理 / 设置 平级切换） │
│ · 会话列表    │  聊天：消息流 + 输入栏 + 状态 / 时钟  │
│ · 世界列表    │  管理：实例 / 时间线 / 版本 / 导入导出│
│ · 时间线列表  │  设置：LLM / 提交 / 外观 / 关于       │
└──────────────┴──────────────────────────────────────┘
```

### 3.1 聊天面

- 消息流（多分段渲染、时间戳）、输入栏（Enter 发送 / Shift+Enter 换行）、生成中状态提示。
- 顶栏：当前世界 / 角色 / 时间线标识 + **世界时钟显示**（历法换算后，仅当前激活时间线）+ 运行状态提示。
- 历史加载：按会话（时间线作用域）滚动加载。

### 3.2 管理面

| 区 | 操作 |
|---|---|
| 实例 | 列表（名称 / 来源 / 创建时间）、**创建**（选择世界包 → 命名 → 创建）、**导入 / 导出**、重命名（全局唯一约束）、删除 |
| 时间线 | 列表、创建、激活 / 冻结、切换（会话绑定）、回滚（破坏性）、提交点查看 |
| 版本 | 手动提交、回滚入口、自动提交开关状态 |
| 时钟 | 世界时间（历法）、**倍率调整**（`[1, 上限]`） |
| 世界包 | 文件管理（选择 / 修改指引）、生成器入口（表单式 / 对话式） |

- 破坏性操作（回滚、删除）需二次确认，文案明确代价（承运行层「界面需明确提示」）。
- 黑箱内数据（事件 / 角色状态 / 记忆）不提供任何查看入口。

### 3.3 设置面

| 组 | 项 |
|---|---|
| LLM | 服务地址 / 模型 / **API Key（UI 写入、读取打码）** |
| 提交 | 自动提交开关（全局）、参数展示（间隔 / 阈值） |
| 世界 | 倍率上限（只读；仅开发者可配）、世界包目录 |
| 外观 | 主题（黑白极简，跟随系统明暗） |
| 关于 | 版本、日志目录（可打开）、诊断 |

## 四、视觉规范（黑白极简）

- 语义色板：黑白语义集（背景 / 墨色文字 / 边框 / 弱化文字），明暗两套；点缀色仅限状态与数据可视化。
- 无衬线字体；卡片 = 1px 描边 + 圆角；无装饰性渐变。
- 具体 token 表在实现首版定（参照 veranima Galaxy 语义集，不整体照搬）。

## 五、生命周期与补算

- 关闭窗口 → **默认最小化到托盘**（核心继续运行，世界持续推进）。
- 托盘菜单：显示主窗口 / 退出。
- 用户显式退出 → 核心与插件停止 → 记下退出时刻（基准）。
- 下次启动 → **补算**：按 `基准 + 流逝 × 倍率` 追赶世界时间；事件 / 生活线按确定性种子补生成；**补算预算有上限**（超出部分摘要化处理，不逐日展开；数值实现后标定）。
- 补算对用户透明：启动后世界时间自然吻合；追赶期间界面显示「正在追赶世界时间」状态。

## 六、错误与诊断

- 核心不可用 / 未就绪：界面给出明确状态 + 日志路径（不静默）。
- 生成失败 / 发送失败：按 UMP 错误模型呈现（可重试项给重试入口）。
- 日志：壳日志与核心日志分离存放（「关于」页可打开目录）。

## 七、与其它模块的接口

| 对方模块 | 接口面 |
|---|---|
| 通道插件层 | 窗口 = UMP 通道客户端（本地 WS）；拆分预留 |
| 世界运行层 | 管理面操作（时间线 / 提交 / 回滚 / 倍率）；世界时钟显示 |
| 世界设定层 | 实例创建 / 导入导出入口；世界包选择与生成器入口 |
| 会话核心层 | 会话列表面、历史加载、生成状态 |
| 角色卡 | 角色选择与生成检查入口（随实例创建流程） |

## 八、实施分期

- **阶段 0**：壳 + 核心 sidecar 监督 + 聊天面（UMP）+ 最小管理面（实例列表 / 创建 / 聊天）+ 设置骨架 + 托盘。
- **阶段 1**：导入导出界面。
- **阶段 4**：时间线 / 版本管理界面（随机制落地）。
- 补算随世界时钟（阶段 0–2）。

## 九、待模块设计项（残余）

- 视觉 token 表（黑白语义集的具体色值，实现首版定）。
- 管理面接口的具体形状（与核心的调用契约，实现级）。
- 补算预算参数与摘要化策略细节。
- 托盘细节（图标状态、菜单项）。
