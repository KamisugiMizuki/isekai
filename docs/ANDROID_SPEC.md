# 安卓端（ANDROID_SPEC）

> 上游总设计：[`DESIGN.md`](DESIGN.md)（总纲） · 本文为「安卓端」模块设计文档
> 来源：2026-09-19 总设计对话整理拆分（V1.9 收敛内容）；未决细则在模块设计阶段补齐。

本模块职责：安卓端能力范围与实现策略（内建聊天、共享生成器、跨端导入导出、无插件）。

## 一、能力范围

#### 能力说明

- 安卓端支持世界实例创建。
- 安卓端支持世界实例对话。
- 安卓端支持世界实例导入导出。
- 安卓端支持世界包文件修改，支持表单式与对话式两种方式。
- 安卓端与桌面端共享世界包生成器。
- 当前版本生成的世界包保证在当前版本可运行。
- 两端版本不同时，按各自版本规则处理。
- 跨大版本不兼容时，先查找转换器。
- 无转换器则提示使用对应兼容版本运行。
- 安卓端不开放插件。
- 安卓端始终使用内建聊天实现。
- 安卓端内建实现遵循统一消息协议。
- 安卓端内建实现保持独立，不随桌面端拆分而同步拆分。

#### 安卓端与桌面端的能力对比

| 能力 | 桌面端 | 安卓端 |
|---|---|---|
| 第三方插件 | ✅ | ❌ |
| 聊天实现 | 内建（可拆为插件） | 始终内建，独立维护 |
| 世界实例创建 | ✅ | ✅ |
| 世界实例对话 | ✅ | ✅ |
| 世界实例导入导出 | ✅ | ✅ |
| 世界包文件修改 | ✅ | ✅（表单式 + 对话式） |
| 世界包生成器 | 共享 | 共享 |
| 角色卡生成与检查 | ✅ | ✅ |
| 时间线管理 | ✅ | ✅ |
| 版本管理操作 | ✅ | ✅ |
| 世界时钟倍率调整 | ✅ | ✅ |
| 倍率上限配置 | ❌（仅开发者） | ❌（仅开发者） |

#### 设计含义

- 安卓端是“无插件版”，但核心体验完整。
- 世界包生成器共享，两端生成结果一致。
- 跨端同步仍为手动，通过导入导出完成。
- 无云同步，无自动同步。
- 版本差异通过各版本规则处理，不强行兼容。
- 跨大版本不兼容时，优先转换，无法转换则提示使用兼容版本。
- 倍率上限仅开发者可配置，两端用户均不可配置。
