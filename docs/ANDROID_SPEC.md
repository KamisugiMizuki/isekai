# 安卓端（ANDROID_SPEC）

> 来源：2026-09-19 总设计对话整理拆分；同日模块深化（技术路线待定：先做桌面端，安卓路线后续评估——本 SPEC 锁能力面与协议面，不锁实现）。

## 一、模块职责与范围

**职责**：安卓端能力范围与协议面约束（内建聊天、共享生成器、跨端导入导出、无插件）。

- 安卓端不是「缩水版」：除插件外核心体验完整。
- 本文件冻结**能力面与协议面**；实现路线（技术栈）待评估（§五）。

## 二、能力范围

- 安卓端支持世界实例创建。
- 安卓端支持世界实例对话。
- 安卓端支持世界实例导入导出。
- 安卓端支持世界包文件修改，支持表单式与对话式两种方式。
- 安卓端与桌面端共享世界包生成器。
- 当前版本生成的世界包保证在当前版本可运行。
- 两端版本不同时，按各自版本规则处理。
- 跨大版本不兼容时，先查找转换器；无转换器则提示使用对应兼容版本运行。
- 安卓端不开放插件。
- 安卓端始终使用内建聊天实现。
- 安卓端内建实现遵循统一消息协议。
- 安卓端内建实现保持独立，不随桌面端拆分而同步拆分。

## 三、协议与格式面（跨端不变式）

- 内建聊天实现遵循**统一消息协议（UMP）**（见 `CHANNEL_PLUGIN_SPEC.md`）。
- 世界包生成器两端**共享**：同一输入生成同一结构。
- 世界包 / 世界实例的**文件格式两端兼容**：同一版本之间可互相导入导出。
- 导入导出规则与桌面端一致（全局同名约束、序号规则、版本检查）。
- 世界包生成器两端共享，两端生成结果一致。

## 四、与桌面端的差异

- 无插件：不提供插件接入位。
- 内建聊天实现独立维护：不随桌面端拆分而同步拆分；两端内建实现可以共享代码，但作为独立模块维护。
- 倍率上限仅开发者可配置，两端用户均不可配置。

设计含义：

- 跨端同步仍为手动，通过导入导出完成；无云同步，无自动同步。
- 版本差异通过各版本规则处理，不强行兼容；跨大版本不兼容时，优先转换，无法转换则提示使用兼容版本。
