## 2. 本次裁决（第一步）

### 2.1 效果 schema：`value` 里放结构体

```json
{"kind": "relation_change", "target": "cc-对方", "value": {"持有者": "cc-本人", "轴": "恩情", "档位": "深"}}
```

| 键 | 约束 |
|---|---|
| `kind` | 必须是 `relation_change`（进 `SUPPORTED_EFFECTS`） |
| `target` | **关系的对方**（角色 / 组织的稳定标识；必须是已登记对象） |
| `value` | **必须是结构体**，且**只允许 `持有者` / `轴` / `档位` 三个键**（多一个即拒） |
| `value.持有者` | **必填**：关系的持有者（必须是已登记对象）。**刻意不从 `target` 反推**——那也是「三件事挤一个字段」的另一面 |
| `value.轴` | 必须是 `RELATION_AXES` 闭集之一 |
| `value.档位` | 必须是 `RELATION_GRADES` 的键（`淡/中/深/极`）——**依旧不接受自由数值** |

> **为什么把结构体放进 `value`**（而不是新增平行字段或顶层键）：核心里所有效果都走
> `kind / target / value / expiry / ...` 这一套共同字段；新增平行字段要动**所有效果**的共同约定与校验路径，
> 而结构体只影响这一个 kind 的校验分支。**「三件事挤进一个字符串」才是要避免的**（`value="cc-x:恩情:深"` 那种），
> 结构体把三件事各自放在命名的键里，校验可以逐键做，读代码时也不靠解析字符串。

### 2.2 消费路径（**声明与消费同批**，A-9b 的教训）

| 步骤 | 做法 |
|---|---|
| 取数 | 复用推进路径已有的 `effect_constraints`：关系效果的 `target` 是**角色标识**，**本来就在下推集合里**（`constraint_targets` 含 `character_id`）⇒ 不需要为它改下推 |
| 写入 | 由事件效果推出 `relation_set(..., basis=事件标识)`——**依据就是那条事件**，满足「无依据不允许变化」 |
| 幂等 | `relation_set` 是 `ON CONFLICT DO UPDATE` ⇒ 同一条效果重算多少次结果相同 |
| 退休语义 | `relation_change` 与设值型同族：把它加入 `SETTING_EFFECT_KINDS`（「当前关系」是设值语义，同 `(from,to,axis)` 只应有一条生效） |

### 2.3 **不接认知投影**（第二步）

关系仍然**只存在于事实层**：角色的认知里看不到它。`tests/test_relations.py` 的边界断言**保持不动**——
这样「本次没有偷偷接认知」是**被测试锁住的**，而不是靠我声明。
第二步（按「是否获知」过滤后再进认知）单独验收，独立的规则版本与兼容性登记。

## 3. 兼容性与规则版本

| 情形 | 行为 |
|---|---|
| 未声明 `relations`、也没有 `relation_change` 效果的包 | **逐字节不变**（不写行、不读表） |
| 声明了 `relations` 但没有 `relation_change` 的包 | **逐字节不变**（v1 行为） |
| 声明了 `relation_change` 的新包 | 世界会不同（关系真的会被事件改变）——**这是新内容的能力** |

⇒ **规则版本不递增**：判据仍是「现有世界包与现有实例的行为逐字节不变」
（与 B-1 v2 / B-3+B-9 v2 同判据）。**注意**：第二步（认知）会改变「角色知道什么」，
那一步**必须重新裁决是否递增**。

## 4. 验收（可反证）

| # | 断言 |
|---|---|
| ① | 合法声明通过；`轴` 不在闭集 / `档位` 不是档位 / `value` 不是结构体 / 多一个键 ⇒ **全部拒绝** |
| ② | `target` 必须是已登记对象（引用闭集） |
| ③ | **机制生效**：注入一条 `relation_change` 后果后，真实 `advance` 让 `relation_state` 出现/更新那一行 |
| ④ | 依据非空：写入行的 `basis` 指向事件标识（不是空串） |
| ⑤ | 幂等：同一条后果重算不产生漂移（同输入同结果） |
| ⑥ | `relation_change` 进闭集 + 有优先级（否则是「包能声明、没人消费」的空效果） |
| ⑦ | **边界断言不变**：v1 的「不接认知投影」那条仍然绿（本次没有越界） |

## 5. 风险

| 风险 | 缓解 |
|---|---|
| 关系被当成「任意数值可调」 | 档位闭集 → 固定千分比；`value` 只允许两个键；自由数值仍被拒 |
| 无依据漂移 | `relation_set` 强制 `basis`；消费路径传事件标识 |
| 悄悄接进认知（串材料） | 本次**不碰认知**；v1 的边界断言保持不动，越界即红 |
| 与 B-7 退休的交互 | 加入 `SETTING_EFFECT_KINDS`；B-7 默认停用 ⇒ 本次无行为变化 |
