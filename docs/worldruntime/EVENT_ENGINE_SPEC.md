## 一、职责与范围

**职责**：事件骨架生成、事实效果、文本固化、事件族与密度、信息传播资格、生活线互动、主动素材、用户引入事件。

**范围外**：最终认知过滤归运行层；主动发言的选择与投递归会话层；事件不得由这些消费者各生成一份。

不变式：**发生了什么、谁获知什么、她是否说出来是三个不同阶段**。

## 二、事件模型

| 字段组 | 内容与保证 |
|---|---|
| 身份与作用域 | 稳定事件标识；世界实例 / 时间线；来源为引擎、用户引入、生活线派生或经校验的角色行动 |
| 时间与因果 | 世界秒、确定的同刻顺序、前置条件、父事件或来源引用；历法时刻仅为呈现 |
| 主体与类型 | 世界 / 角色，参与者或受影响标签，政治 / 灾害 / 节庆 / 风闻 / 角色经历 |
| 事实骨架 | 是否发生、规模、参与方、可执行的状态效果与有效期；只由受支持规则确定 |
| 实情文本 | 对事实骨架的描述；供内部一致性使用，不直接注入角色上下文 |
| 说法集合 | 每条含独立标识、文本、来源渠道、受众条件、最早传播时刻与可信线索；可为真或假 |
| 角色获知记录 | 某角色在何时经何来源获知哪条说法 / 观察；可能获知不等于已经获知 |
| 素材资格 | 是否有分享价值及重要度；每角色还需通过认知过滤，不是全局发送开关 |

- 事件事实与最初文本写入后不可原地改写；后续澄清、后果或新说法以新记录关联原事件。
- 没有说法且没有任何角色观察到的事件仍可影响世界，但不能因此直接成为角色台词。
- 「公开 / 宫廷 / 本地 / 远方」等是世界包声明的叙事标签，不是坐标或路网系统。
- 史料条目落入说法集合：条目可对事件或命题作表述，**不要求所述命题为真**。「某项指控被载入史书」可作为事件；「被指控之事真实发生」只是该说法指称的命题，不自动产生事实效果（沿用风闻规则）。
- 说法之间的矛盾是常态而非异常：同源异文（讹传、记混）、立场改写（正统改写、对敌抹黑、为尊者讳）、残本流失。任何体裁的说法均可真实、片面或完全虚构，不为神话或创世记述单设真假权限。
- **缺载是合法形态**：不要求每个来源覆盖每个事件；「已确认缺载」与「尚未生成 / 展开」必须区分，惰性展开不得把缺载补成有载。缺载本身不证明刻意删改，认定改写须有设定或来源依据，且该依据同样经认知过滤。
- 事实参与者、效果目标与结构引用必须指向登记实体或角色；纯署名贡献者与说法中的指称不取得事实资格（登记门槛见 `WORLD_SETTING_SPEC.md` §2.2）。
- **效果须声明失效方式**：随诱因结束即失效 / 持续存在直到被合法事件解除 / 有条件的自然恢复，三类须在模板中可区分；不能把统一到期当成全部恢复。
- **后果持续期间照常参与因果**：仍有效的后果进入相关生活安排与后续事件前置条件，直到被解除或转为新常态；正向成果同样不因事件过期自动消失。
- **错误说法可以导致真实措施**：合法获知与采信可促成受支持的措施或角色行动；指控真伪、措施是否发生、措施是否撤销分别判定。澄清只改变已获知者的认知，不自动撤销措施或抹去已发生的损失。

## 三、生成（确定性骨架 + 文本一次固化）

### 3.1 候选、判定与事实效果

- 依据锁定种子、历法日、密度与世界规则版本产生候选槽；数据格式版本、应用版本和文本模型指纹不参与候选抽样。
2. 按世界时刻与稳定顺序处理槽，读取该时间线的前序状态，检查来源、参与者、日历条件与前置事件。
3. 合法候选产生事实骨架与效果；不满足条件则不发生，不能为了凑密度凭空添加实体或违反世界规则。
4. 应用效果、写事件、更新受影响生活线与推进水位在同一一致性边界完成。

5. 恢复、解除与新常态由后续合法事件或已声明的自然条件产生；没有合法依据时保留后果，不为凑故事强行续发灾害、恢复或转折。
6. 制度类效果（政令、资格、义务与职位的延续 / 失效 / 空缺与承接）按世界包声明规则作用于角色与登记实体；空缺期间哪些事务继续、哪些暂停须可判定，不默认全部停摆或立即继任。

**相同候选不等于相同结果**：相同种子 / 日期 / 规则给出相同抽样候选；分叉后若前序状态不同，实际发生的事件可以不同。可复算承诺针对同一锁定设定、种子、前序状态、规则版本及已固化输入。

### 3.2 LLM 边界

- LLM 将既定骨架表达为实情与说法文本，允许不同口吻与误解；不能自行决定发生时间、数值效果、参与者生死、设定公理或额外的因果转移。
- 文本校验通过后固化；失败有界重试，仍失败用不新增事实的模板。读取、换消费者、重启不重新生成已固化文本。
- 并发命中同一槽只有一份产物被采纳；生成结果绑定来源水位与运行世代，回滚后的迟到结果作废。
- 在线和离线可以采用不同语言表述路径，但必须得到等价事实骨架与效果；不保证两次独立 LLM 调用逐字相同。
- 世界自演化只能在锁定公理下增加有依据的运行事实；阶段 6 引入更深的规则推导，不能把「文本写了」当成「世界已经发生」。

### 3.3 历史回填（实例创建期）

- 与运行期产出共用同一事件模型与规则；分时代抽样、独立预算，不占运行期每日密度；无合法候选则留白。创建期时序与固化边界见 `WORLD_SETTING_SPEC.md` §3.6。
- 文本生成受骨架约束，不由文本反向决定事实效果或发生时间。
- 回填记录不再次施加效果（灾害、性格冲击、获知）；素材侧约束见 §七。
- 回填期一并确定要点人物的出生 / 死亡与活动区间，并生成相应生死事件与死讯说法；这类记录同样不重复施加效果。

### 3.4 既定内容的惰性展开

被追问、被引用或成为剧情支点时，可将已有条目展开为段 / 本末；通过校验后以关联原条目的**新增派生记录**固化，不原地改写事件或最初文本。

- **只展开既定内容**：依据已确定的事实与该传本的说法，不新增尚未确定的参与者、生死、关键原因、结果或状态效果——「没有推翻旧句子」不足以证明合法，补出死因或幕后责任人同样可能是在创造新事实。
- **留白不临场填真相**：依据不足就保留不知道，不把「未展开」冒充该来源未记载；不同来源之间既定的矛盾仍合法，不以实情强行改正错误史料。
- **物化不等于获知**：系统生成文本不虚构读书经历，只能返回角色原本掌握范围内的展开；新增范围须经合法接触与获知。
- **共同过去不随提问改变**：只使用该传本对应的固化输入，不使用后来局势、分叉后对话或角色私有知识；同一实例中同一传本 / 条目复用已采纳的展开结果，不按角色或时间线各写一份相冲突的史料。
- **派生表示不是第二份真值**：展开不产生事实效果；获知范围、引用经历与派生记忆随角色与时间线版本化，回滚撤销后来的获知，缓存不得越权返回。

## 四、事件族与预算

**事件密度是世界包必填的体裁属性**。以下为建议起点，参数随生成规则版本固定后才运行：

| 密度档 | 每历法日世界级随机事件目标区间 |
|---|---|
| 稀疏 | 0–1 件 |
| 常规 | 1–3 件 |
| 丰盛 | 2–5 件 |

- 上限是硬预算；下限是有足够合法来源时的目标，不是强迫世界每天出事。
- 先决定当日数量预算，再从合法候选中按稳定顺序选择；不得只做独立概率抽样却宣称有严格每日上限。
- 世界包声明各事件源的适用族、前置条件、受众与效果模板。引擎支持四族不代表每个世界必须出现全部四族。
- 节庆遵循世界历法与包内周期，不能随机日期冒出指定节日。先为固定节庆预留当日世界级上限内的名额，再从剩余额度抽样随机事件；固定事件不因随机抽到较小预算而被丢弃。包内固定事件已超过密度档上限时须在创建前校验报错，不在运行时悄悄漏节日。
- **惯例形态可变，节日日期与预算不变**：同一节庆在不同群体可以有不同做法（沿用、改换或停办某项活动）；变更须有来源与生效时刻并影响后续活动，不得借文化演化新增超预算节日或改写历法。
- 用户显式引入事件不被随机密度丢弃；角色经历分别预算、按真实活动产成，不为增加故事量逐 tick 记一条。

| 族 | 题材示例 | 典型信息范围 |
|---|---|---|
| 政治 | 政令、组织动向、边患 | 公开 / 特定机构 / 传闻 |
| 灾害 | 天灾、事故、封路的叙事后果 | 本地 / 公开 |
| 节庆 | 节日、集市、典礼 | 公开或特定群体 |
| 风闻 | 传闻、谣言、异象说法 | 指定传播渠道 |

风闻的事实可以是「某种说法开始流传」，**不等于说法指称的事为真**。

**生死事件**：登记实体的寿终由寿命模型与世界时刻推出，登记为事件并可产生死讯说法（按渠道传播与被获知）；不属于四族的抽样预算，单独记账，不占每日随机密度。

- 世界包至少声明一类合法、受引擎支持的事件源；族数不设创建门槛，四族不必齐备（最低标准见 `WORLD_SETTING_SPEC.md` 附录 D）。

## 五、可见性与跨角色

- 同一时间线共用事件真值；各角色按卡片渠道、活动经历与获知时间获得不同说法。
- 事件发生、传播、角色接触分别记时；未来槽、未来计划、尚未传播的新闻不进入当前认知。
- 公共说法不等于全员公开；无相应渠道的硬约束角色不能仅因「公开」标签获知。
- 亲历经观察投影形成角色可见片段；不复制完整实情。相关经历 / 记忆保留该观察或说法来源。
- 可信权威说法也可能高确信但客观错误；置信表达归记忆与认知，不以「来自说法层」一律设成低置信。
- 第三方插件、UI、主动生成器均不能直接读取实情文本。

## 六、与生活线的互动

- 世界事件按受影响标签与角色条件覆盖**生效时刻后的**活动片段；过去活动不改，已发生经历不被取消。
- 多事件同刻覆盖采用固定优先规则与稳定标识排序，结果不受消费者执行先后影响；具体优先表在事件模板中声明。
- 生活线产出经历时引用原活动 / 事件；世界事件引发活动变化、活动再派生经历不能无限循环。
- 角色建议的世界行动亦须明确前置条件和效果，进入同一事件路径；用户自然语言本身没有写世界状态权限。
- 首批可执行效果须声明是否能约束活动、表达或恢复条件；身体类效果只按题材选择受支持的闭集（例如受伤、疾病或疲劳），不默认建立健康值、饥饿值等通用数值系统。
- 代表性内容至少包含一条可验收的因果链：诱因发生、后果持续、后续合法事件或行动响应，最后解除或形成新常态；没有合法依据时允许链条停在持续后果。
- 环境类效果只能引用世界包已声明的环境类型、范围和变化方式；不得以事件文本临时创建天气、温度、声响或其精确数值。角色观察由运行层按认知条件投影。
- 事件链中的“后续响应”可以是角色行动、生活线调整、制度反应或新的世界事件；其参与者、动机、阻碍和效果必须分别有登记实体、角色可知依据或世界包规则。引擎不得为了完成故事链替角色生成未获知的目标。
- 事件链允许停在失败、拒绝、未解决或不圆满的新常态；“收束”表示当前局部问题获得合法状态结果，不表示世界真相全部揭晓或所有角色达成共识。

## 七、主动发言素材

- 事件具有分享价值且**该角色已获知**后，才能形成该角色的素材候选；不能把带秘密的原始事件整条推给生成器。
- 分享价值可以来自它改变了旧话题的意义（补全、质疑或重新解释角色已谈过的片段），不只来自事件规模或新鲜程度；仍须满足已获知、时效与统一配额，不新增旁路发送。
- 素材携带来源、角色、时间线、发生与获知时间，消费记录随该线版本化。
- 素材不是消息。世界推进不依赖发送成功；发送失败也不撤销她已经经历或获知的事。
- 择时、过期、离线候选合并与跨通道唯一投递见 `SESSION_CORE_SPEC.md` §五。
- 历史回填产物不因导入 / 启动批量成为新近主动素材；角色后来合法读到旧史料属于新的获知经历，不是历史事件重演。

## 八、用户引入事件（世界修改路径）

这是**显式管理操作**，不是聊天命令的隐式副作用。用户仍不成为世界内人物；普通对话影响世界只能经角色行动。

1. 用户选择来源提交，或要求从当前一致水位分叉，并描述修改意图。
2. 系统生成事件草案：即时 / 预约类型、发生时刻、前置条件、事实效果、拟传播说法与受众。草案仅展示用户提供的意图及可确认部分，不展示既有隐藏事实。
3. 校验锁定公理、可执行效果与所选来源点的状态。**可以改变当前局势，不能改写过去或公理**；例如以合法新事件改变某职位的持有者，不等于篡改该职位原先的历史。
4. 无法表达为受支持事件时明确拒绝，不把自由文本当作已执行效果；若需改变历法、世界公理或角色卡，改世界包后创建新实例。
5. 冲突说明不透露未知秘密及其内容；可以给不泄密的规则说明或让用户调整意图，不能借「可行近似」泄露隐藏真相。
6. 用户确认后，基于已预览的确定来源点，**原子创建新时间线并注入事件**；失败不留下半条线。即时事件的发生时间固定为新线创建 / 确认提交水位；预约事件只写入待执行状态，不在确认时施加效果、产生经历或授予获知。
7. 若用户选择「当前」且预览后来源已变化，重新校验；影响草案含义时重新确认，不能静默换一个分叉基础。
8. 原线保留；新线默认冻结，由用户明确激活。请求重试返回同一创建结果，不重复造线或重复注入。
- 预约事件到达目标世界时刻时重新读取该线一致快照，重新检查前置条件、参与者、规则版本和目标线成员资格；条件失效则记录未执行 / 取消结果，不强行执行。成功、失败、取消和重试沿稳定事件标识幂等，回滚撤销待执行状态及其后果。

## 九、与其它模块的接口

| 对方模块 | 契约 |
|---|---|
| 世界运行层 | 事件模型唯一持有、状态效果、生活线覆盖、角色获知、快照与任务失效 |
| 会话核心层 | 经过认知过滤的素材；用户对话不直接成为管理修改 |
| 世界设定层 | 种子生成策略、事件源、密度、双轨内容及稳定引用 |
| 角色卡 | 渠道、初始知识、活动模板及受影响条件 |
| 记忆子系统 | 角色已获知的说法 / 已发生的经历及其来源；不是原始实情 |

## 十、实施分期

- **阶段 3**：世界级四族的可用模板、角色经历、事件效果与获知链、素材资格。
- **阶段 4**：时间线机制就绪后启用用户引入事件。
- **阶段 6**：深化规则推导；新增运行事实仍须有来源、效果与认知路径。

## 十一、待模块设计项（残余）

- 稳定哈希的具体算法与编码、各密度档参数、模板优先级表。
- 事实效果闭集与可支持的事件源类型；首版不能执行的类型须由生成器与校验器共同拒绝。
- 文本生成提示词与兜底模板、传播延迟参数。
- 历史回填的候选槽语义与体裁选取规则；惰性展开的触发条件、预算与派生表示的存储方式。
- 生死事件的预算口径与寿终判定边界（历法年 / 世界秒换算）。
- 首批效果闭集与「失效方式」的模板表达、恢复条件与同刻多效果优先规则；能展示完整余波链的代表性世界内容。
- 制度类效果的声明对接：选用哪些组织与职权，如何声明空缺、延续、继任与终止条件。
- 文化惯例的演化路径与声明方式：选用哪些群体与惯例，如何与既有节庆、生活模板与历史引用对齐。
- 首批效果闭集与身体 / 活动限制的映射；未支持的效果由生成器与校验器拒绝。
- 代表性因果链的内容样例；样例不得依赖临场补造事实或固定每日事件配额。

## 附录 A：种子与骨架（设计级）

- 候选槽建议起点仍为稀疏 2 / 常规 4 / 丰盛 8；槽数是搜索空间，不等于发生数量。
- 抽样输入包含锁定世界种子、生成规则版本、密度、历法日与槽序；使用固定编码、固定哈希算法，禁止依赖进程随机化的语言内置 `hash()`。
- 当日候选排序、数量抽样与类型选择可纯函数求值；实际执行还需前序状态与前置条件。随机候选的失败处理规则也必须固定，不能重抽到成功为止。
- 世界种子、规则版本与已固化事件标识随导出 / 分叉保留；导入产生的新本地实例 ID、机器时间、线程顺序不得改变事件抽样。
- 同一逻辑事件重试沿用稳定标识；分叉后的记录归各线命名空间，公共祖先引用只读。

## 附录 B：行为验收

1. 同一输入在桌面 / 安卓、不同进程与不同补算分批下得到相同骨架、效果与事件顺序。
2. 两线共同过去相同；其中一线引入事件改变前置条件后，后续结果允许分化，不能机械复制另一线的事实。
3. 每日随机事件不越预算；无合法来源时可少于目标下限；固定节日不漂移日期。
4. LLM 超时、重复回包或生成了骨架外的事实时，世界状态不被语言产物偷偷改写。
5. 不同角色只能获知相应说法；角色尚未接触的事件不能进入记忆或主动台词。
6. 同刻覆盖与跨日补算不改过去，不重复产经历，不形成事件派生循环。
7. 用户修改在确认后仅作用于新线；失败或重试不改原线、不创建半成品；校验提示不泄露世界秘密。
8. 完全虚构的指控可存在于普通史料并影响角色判断，但不会让指控内容成为实情或直接执行其所述效果。
9. 不同提问顺序、重复展开及分叉后的查询不改变既定事实与共同传本；不能从一句含糊记载临场补出未经确定的死因或责任人。
10. 尚未生成不能冒充缺载，缺载不能直接当作删改证据。
11. 事件参与者或效果目标指向未登记对象时校验失败；含未登记名字的传闻仍可被获知与讨论，但不产生事实效果。
12. 灾害、封锁或事故结束后，后果仍参与后续生活安排与前置条件，直到满足恢复条件或转为新常态；澄清不自动撤销已施行的措施。
13. 职位持有者离任或死亡后，政令、资格与事务按声明规则分别延续或暂停；空缺不默认全部停摆或立即继任，也不让所有角色自动知晓。
14. 同一节庆中不同群体可保留不同做法，日期与预算不变；变更不改写旧记录，也不扩大任何角色的已知范围。
15. 一条代表性事件链能从诱因经持续后果走到合法响应与解除 / 新常态；若没有合法恢复条件，后果保持有效而不是被文本强行收束。
16. 首批身体类效果只影响声明过的活动、表达或恢复条件；未声明的健康数值不会被生成器临场添加。
17. 预约事件在目标时刻前不产生效果、经历或获知；到期重新校验前置条件，条件失效则记录取消 / 未执行；重启和重试不重复施加效果，回滚撤销待执行记录。
